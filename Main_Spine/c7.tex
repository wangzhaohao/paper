\xchapter{总结与展望}{Conclusions and Outlook}
\label{chap:conclusions_outlook}

\xsection{主要结论}{Conclusions}

快堆MOX燃料元件在高功率密度、高温度梯度和强中子辐照条件下服役，其温度、组分、微观结构、裂变气体行为以及力学响应之间存在显著的双向耦合关系。针对传统燃料性能分析中总体控制关系与材料闭合模型衔接不足、微观演化过程考虑不充分、多物理场强耦合求解困难以及高保真模型在线计算代价较高等问题，本文围绕多物理场总体建模、材料行为与微观结构演化、非线性热--气--力耦合实现、燃料棒级验证和全寿期完整热力场快速预测五个方面开展研究，主要结论如下。

\begin{enumerate}[label={（\arabic*）},leftmargin=2.8em]
	\item 建立了氧化物燃料元件多物理场控制方程与材料闭合体系。面向燃料芯块、燃料--包壳间隙、包壳、棒内自由体积及冷却剂通道，统一建立热传导、准静态力学、微观结构与组分输运、裂变气体及棒内气体状态、间隙传热和冷却剂热工边界之间的总体耦合关系；在此基础上，选取并整理MOX燃料以及SS316、D9和HT9等典型快堆包壳材料的热物性、力学与辐照行为模型，形成与总体控制方程相配套的材料闭合体系，为后续微观演化、非线性热--气--力耦合和燃料棒级计算提供统一的模型基础。
	
	\item 建立了考虑气孔迁移、锕系元素重分布和氧金属比演化的强耦合模型。针对高温度梯度下气孔向燃料中心迁移并引起组织重构的问题，构建了孔隙输运方程，比较了经验关系式与Rand--Markin多组分热力学模型对气孔迁移速率的描述，并通过稳定化离散提高了对流占优条件下的数值稳定性。针对钚重分布，建立了同时考虑化学扩散、热扩散和气孔迁移增强效应的组分输运模型，能够再现钚向高温区域富集的主要趋势，并进一步扩展至镅元素迁移分析。针对O/M演化，建立了热扩散与化学扩散耦合的氧迁移模型。计算结果表明，初始化学计量状态会显著影响氧的径向迁移方向和幅度，而局部O/M变化又会通过蒸气压、热导率、熔点及迁移驱动力反馈影响气孔迁移和锕系元素重分布。
	
	\item 完成了非线性力学、裂变气体行为和间隙传热模型的统一数值实现。针对燃料和包壳材料中塑性、蠕变及多种非弹性应变共同作用的问题，建立了热弹塑性控制方程的有限元离散形式，并采用径向返回算法在材料积分点处隐式更新应力、塑性应变和硬化变量。裂变气体方面，分别实现了适用于工程计算的ForMas模型和细观机理程序SCIANTIX的耦合接口，完成温度、裂变率、燃耗、应力及气体状态变量的双向传递。进一步将裂变气体释放、气腔压力、混合气体组分和间隙换热系数纳入统一时间推进过程。单元级、子模型级和耦合接口级验证结果表明，所建立的数值算法能够保持主要物理趋势和状态变量演化的一致性，为燃料棒长期热--力耦合计算提供了稳定的计算基础。
	
	\item 建立了面向MOX燃料棒的验证计算方法。基于公开基准数据和补充实验数据，构建了燃料中心温度与裂变气体释放的棒级计算模型，并分别采用ForMas和SCIANTIX描述裂变气体行为。已完成的中心温度算例能够总体再现实验数据随功率和燃耗变化的主要趋势，说明所建立模型能够描述MOX燃料棒的稳态热响应。高燃耗阶段局部偏差增大，表明燃料热导率退化、初始和演化间隙、裂变气体释放以及接触换热仍是影响预测精度的关键因素。结果表明，中心温度、裂变气体释放与间隙换热应作为耦合过程处理，通过迭代反馈实现一致求解，而不宜采用彼此独立的单向计算方式。
	
	\item 构建了基于POD--LSTM的燃料性能全寿期完整热力场快速预测方法。以经过验证的二维RZ燃料棒模型生成高保真场快照，通过网格敏感性分析选取包含5717个节点和5000个单元的统一网格。采用POD将温度、径向位移和轴向位移共17151维节点输出压缩为28维低阶系数，并首先以插值和POD--GPR模型建立固定功率倍率下的预测基准。在此基础上，构建了包含40条训练历史、10条验证历史和10条独立盲测历史的变功率数据集，采用时间、瞬时功率、功率变化率和累积功率积分作为序列特征，利用LSTM预测POD系数增量并恢复完整二维场。独立盲测中，温度、径向位移和轴向位移的平均相对$L_2$误差分别为1.256\%、1.528\%和2.549\%。单条109步历史的系数预测与全寿期完整热力场重构平均耗时为$0.0743\,\mathrm{s}$，独立在线示例的总计算时间为$0.06203\,\mathrm{s}$，表明该方法能够在训练数据包络内快速获得全寿期温度场和位移场。
\end{enumerate}

\xsection{主要创新点}{Main Innovations}

本文的主要创新点概括如下。

\begin{enumerate}[label={（\arabic*）},leftmargin=2.8em]
	\item 建立了快堆MOX燃料微观结构重构、多组分迁移与氧化学状态演化的统一耦合模型。区别于将气孔迁移、钚重分布和O/M演化分别处理的传统建模方式，本文以温度场、氧分压、蒸气压和局部材料状态为共同耦合变量，在统一有限元框架中描述孔隙迁移、中心孔形成、钚及镅再分布和氧迁移过程。模型同时考虑固相扩散、热扩散及气孔迁移增强效应，并将O/M对热物性和迁移驱动力的反馈纳入计算，从而形成“微观结构—组分分布—热化学状态”相互作用的闭环描述，为分析高温度梯度和高燃耗条件下MOX燃料的组织与组分演化提供了更完整的模型基础。
	
	\item 构建了非线性力学、细观裂变气体行为与间隙传热相耦合的隐式数值实现框架。本文将基于$J_2$塑性的径向返回算法用于燃料和包壳多非弹性本构的局部隐式积分，并在统一时间推进过程中耦合ForMas工程模型、SCIANTIX细观机理模型及间隙换热模型。通过外部机理程序状态变量的持续传递与回写，使晶内和晶界气体演化、气体释放、气腔压力、混合气体导热、间隙闭合及力学变形能够相互反馈。所建立的“局部本构积分—细观状态更新—全局热力平衡”分层计算方式，提高了复杂燃料性能模型的模块化程度，并为长期辐照条件下多物理场强耦合计算提供了稳定的实现途径。
	
	\item 提出了变功率历史驱动的POD--LSTM燃料性能全寿期完整热力场快速预测方法。该方法不是仅对最高温度或最大位移等标量进行回归，而是首先利用POD提取温度场、径向位移场和轴向位移场的低维空间模态，再利用具有历史记忆能力的LSTM预测低维系数随功率历史的演化，并在任意输出时刻恢复完整二维节点场。模型采用系数增量预测、可训练循环初始状态以及按完整功率历史划分训练、验证和盲测数据的策略，降低了初始状态误差和时间点随机划分引起的数据泄漏风险。独立盲测和在线示例表明，该方法能够在训练包络内以百毫秒以内的计算代价获得全寿期完整热力场，为高保真燃料性能模型由离线计算向快速运行历史分析和在线状态评估扩展提供了技术途径。
\end{enumerate}

\xsection{研究展望}{Research Outlook}

本文针对氧化物燃料元件服役行为建立了包含热传导、非线性力学、微观结构演化、组分迁移、裂变气体释放及间隙传热的多物理场分析框架，但各物理过程的建模精细程度和验证范围存在差异。其中，热传导、燃料变形、裂变气体释放和间隙传热主要采用连续介质及已有工程模型描述；气孔迁移、Pu/Am再分布和O/M演化采用连续场输运方程与相应热力学关系计算，尚未显式解析全部晶粒、气孔及裂纹尺度的演化机制。此外，燃料开裂与碎块重排、裂纹网络中的气体输运、高燃耗组织演化以及复杂包壳辐照损伤等过程仍需进一步完善。上述简化可能影响模型在高燃耗、强瞬态及复杂燃料–包壳机械相互作用条件下的预测能力，因此，本文结果的应用应结合具体模型配置和实验验证范围进行评价。结合本文模型的适用范围及燃料性能分析的发展趋势，后续工作可重点围绕以下三个方面展开。

\begin{enumerate}[label={（\arabic*）},leftmargin=2.8em]
	\item 深化热化学、微观结构与热--力行为的跨尺度耦合。本文采用连续介质方程和经验闭合关系描述气孔迁移、Pu/Am再分布、O/M演化及裂变气体行为，部分关键参数仍依赖有限工况下的实验拟合。后续可将热力学数据库、相场或细观组织演化模型与燃料棒性能计算相结合，进一步描述晶粒长大、高燃耗结构、裂纹网络以及孔隙和裂纹内的气相输运，并建立细观状态向热导率、肿胀、蠕变和断裂参数传递的尺度转换关系。在此基础上，应加强裂变气体、燃料几何演化、间隙传热和芯块--包壳机械相互作用的一致性计算，扩展模型对高燃耗、非化学计量MOX燃料以及功率快速变化工况的适用能力。
	
	\item 建立面向模型可信度的分层验证与不确定性量化体系。现有验证以中心温度和寿期末裂变气体释放率为主，尚不足以约束多物理模型中的全部关键过程。后续可按照材料参数与单效应试验、微观组织与组分分布、燃料棒综合辐照试验以及功率提升和瞬态试验的层次构建验证矩阵，并将中心温度、径向组分分布、中心孔尺寸、裂变气体释放、棒内压、包壳应变和燃料--包壳接触状态纳入联合评价。通过全局敏感性分析、参数校准和不确定性传播，区分材料参数、运行边界、实验测量及模型形式误差对计算结果的贡献，给出预测区间、适用范围和安全裕度，从而提高模型在燃料设计分析和安全评价中的可追溯性与可信度。
	
	\item 发展高保真模型、快速代理模型与运行数据协同的可信预测方法。本文建立的POD--LSTM模型已能够在固定几何、固定冷却剂边界和训练功率历史包络内快速恢复全寿期热力场，后续应将燃料与包壳材料、几何尺寸、初始间隙、充气状态及冷却剂条件等共同纳入参数空间，并研究适用于不同网格和几何的场表示方法。可进一步结合多保真学习、物理约束和算子学习方法，减少高保真样本需求，同时引入误差估计、超出训练包络识别和自适应补充样本机制，明确代理模型的可信边界。在具备运行数据的条件下，还可利用数据同化和在线参数更新修正燃料内部不可直接测量的状态，形成高保真模型、降阶模型与监测数据之间的闭环，为燃料元件数字孪生、状态评估和异常工况快速分析提供基础。
\end{enumerate}
