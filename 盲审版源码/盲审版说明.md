# 盲审版说明

本版以当前 `paper` 工程及已调整的排版为基础，单独生成，不覆盖实名版源码或实名版 PDF。

- 中英文题名页、答辩人位置：作者及导师改为匿名，中英文姓名均已处理。
- 保留致谢、常规评阅人名单、答辩委员会会议决议的章节标题及页面；通过模板 blind 选项隐藏具体内容。
- 研究成果及被引用的本人论文中，作者和导师姓名改为匿名；相关文献的内部引用键同步匿名化。
- PDF 作者元数据清空。
- 正文、公式、图表、参考文献的编号机制以及上一轮排版调整保留。
- 研究成果的题名、期刊、年份、DOI 等信息仍保留；本轮按要求处理姓名，未删除研究成果章节。

## 使用

`学位论文_盲审版.pdf` 为可直接查看的成稿，另存一份至原 `paper` 目录的 `main-blind.pdf`。

`论文盲审版源码.zip` 是独立编译工程，解压到单独目录后，入口为 `main.tex`。不要将整个压缩包覆盖到实名版目录。

编译顺序：XeLaTeX → Biber → XeLaTeX → XeLaTeX（重复至目录及交叉引用稳定）。符号表已改为由 LaTeX 直接生成，无需单独运行 Makeglossaries。
