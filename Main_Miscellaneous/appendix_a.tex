\chapter{SCIANTIX耦合接口说明}
\label{app:sciantix_interface}

为实现裂变气体细观行为与燃料棒多物理场计算的耦合，本文将开源裂变气体行为程序SCIANTIX编译为静态库，并集成至自主开发的Miracle多物理场分析框架中。SCIANTIX基于物理机理描述裂变气体的产生、扩散、气泡成核、生长与释放等过程。本附录重点说明SCIANTIX接口的设计、调用流程、关键数据结构及变量映射关系。

\section{接口框架与调用流程}
为实现SCIANTIX与MOOSE多物理场框架的集成，本文设计并实现封装类\texttt{SciantixWrapper}。该封装类继承自MOOSE的\texttt{Material}基类，在有限元积分点尺度上管理裂变气体状态演化及其与场变量之间的数据交换。
\subsection{设计原则}
\begin{enumerate}
	\item 模块化封装：将SCIANTIX计算接口封装为MOOSE材料类，统一管理输入、状态更新与输出。
	\item 线程安全：通过互斥锁机制处理 Sciantix 内部状态变量的并发访问。
	\item 状态保持：利用 MOOSE 的状态变量特性，在时间步间持久化存储裂变气体状态。
	\item 单位转换：自动完成 MOOSE 物理量（SI 单位）与 Sciantix 内部单位间的转换。
\end{enumerate}

\subsection{输出变量计算}
计算完成后，Wrapper从 \texttt{Sciantix\_variables} 数组中提取宏观感兴趣的量。裂变气体释放份额（FGR）和气态肿胀（Swelling）的计算逻辑如代码清单\ref{lst:sciantix_swelling}所示。

\begin{lstlisting}[language=C++,
	literate={-}{-}1, 
	basicstyle=\small\ttfamily,      % 设置字体大小和等宽字体
	keywordstyle=\color{blue}\bfseries, % 关键字高亮
	commentstyle=\color{gray},       % 注释颜色
	numbers=left,                    % 行号显示在左侧
	numberstyle=\tiny\color{gray},   % 行号样式
	frame=tb,                        % 上下加边框
	breaklines=true,                 % 自动换行
	caption={输出变量的提取与计算},    % 标题 
	label={lst:sciantix_swelling}
	]
	// 提取释放量与产生量 (单位: atoms/m3)
	double Xe_released = Sciantix_variables[6];
	double Kr_released = Sciantix_variables[12];
	double Xe_produced = Sciantix_variables[1];
	double Kr_produced = Sciantix_variables[7];
	
	// 计算裂变气体释放份额 (防止分母为0)
	const double released_atoms = std::max(0.0, Xe_released + Kr_released);
	const double produced_atoms = std::max(0.0, Xe_produced + Kr_produced);
	_fission_gas_release[_qp] = released_atoms / (produced_atoms + 1e-30);
	
	// 提取并汇总气态肿胀 (分数形式)
	_inter_buble_conc[_qp] = Sciantix_variables[25];
	const Real intra_swelling = Sciantix_variables[24]; // 晶内气泡肿胀
	const Real inter_swelling = Sciantix_variables[36]; // 晶界气泡肿胀
	
	const Real solution_swelling = (_iDiffusionSolver == 3) ? Sciantix_variables[68] : 0.0; // 固溶肿胀
	
	const Real hbs_swelling =
	(_iHighBurnupStructureFormation != 0 && _iHighBurnupStructurePorosity != 0)
	? Sciantix_variables[55] * Sciantix_variables[56]
	: 0.0; //高燃耗肿胀
	
	_gaseous_swelling[_qp] = intra_swelling + inter_swelling + solution_swelling + hbs_swelling;
\end{lstlisting}
